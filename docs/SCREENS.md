# SCREENS — 화면/기능 목록

## 공통
- S0. 로그인 화면 (이메일/사번 + 비밀번호)

## 직원용 (모바일 대응, 반응형)
| 화면 | 주요 기능 |
|---|---|
| E1. 홈(내 상태) | 현재 상태 표시, 출근/퇴근 버튼, 상태 변경 버튼(본사근무/고객사상주/외근/회의/이동/재택/야간작업/대체휴무/휴가) |
| E2. 고객사 상주 도착체크 | 도착 체크 버튼, 마지막 확인시각 표시 |
| E3. 휴게 | 휴게 시작/종료 토글 |
| E4. 야간근무 | 야간근무 시작/종료, 종료 시 전환 후보 안내 |
| E5. 대체휴무/보상휴가 신청 | 전환 후보 목록 확인 → 정식 신청, 잔여 휴가 표시 |
| E6. 내 근로시간 | 일/주/월 근로시간, 초과근무 여부 |
| E7. 내 이력 | 출퇴근/상태변경/승인 이력 타임라인 |
| E8. 내 프로필 | 이름/소속/직군/근무유형 표시(읽기전용) |

## 관리자용 (데스크탑 최적화)
| 화면 | 주요 기능 |
|---|---|
| A1. 전사 상황판 (첫 화면) | 상태별 인원 수 요약, 부서/고객사 필터, 상태 색상 구분 |
| A2. 부서별 현황판 | 부서 선택 → 팀원별 현재 상태/근로시간 리스트 |
| A3. 고객사별 상주 현황판 | 고객사 선택 → 상주자별 도착여부/상태/마지막확인시각 |
| A4. 예외 알림 현황 | 미출근/장시간근무/야간근무 후 미전환/미확인 목록, 심각도 표시 |
| A5. 직원 상세 조회 | 개인 근태/상태 이력(역할별 필드 마스킹), 조회 시 감사로그 자동 기록 |
| A6. 승인함 | 대기중 승인 목록(초과근무/야간근무/대체휴무/정정), 승인/반려 처리 |
| A7. 정책 설정 | policy_settings 값 그룹별 편집 화면(폼) |
| A8. 파일럿 대상 관리 | 파일럿 그룹 생성/대상자 추가/기간 설정 |
| A9. 감사로그 조회 | 기간/사용자/액션타입 필터 검색 |

## 인사/운영용
| 화면 | 주요 기능 |
|---|---|
| H1. 근무정책 설정 | 탄력근무 단위기간, 직군별 근무정책 |
| H2. 야간근무 보상방식 설정 | 대체휴무/보상휴가/수당 중 선택, 전환비율 |
| H3. 휴게/보관기간 설정 | 휴게 기준시간, 데이터 보관기간 |
| H4. 리포트/정산 추출 | 기간/부서/고객사 필터 → CSV 추출 |

## 파일럿 운영용
| 화면 | 주요 기능 |
|---|---|
| P1. 파일럿 전용 리포트 | 참여율, 상태변경 빈도, 알림 발생 건수 |
| P2. 이슈 피드백 목록 | 파일럿 참여자가 등록한 버그/UX/정책 피드백 |
| P3. 운영 통계 대시보드 | 파일럿 그룹 전체 요약 지표 |

## UI 원칙 반영
- 첫 화면은 A1 전사 상황판
- 상태 색상: 근무중(녹색 계열), 이동/외근(파랑 계열), 휴가/대체휴무(회색), 경고/알림(주황~빨강) — 팔레트는 `frontend/src/theme`에서 관리, 과도한 색 사용 지양
- 직원 화면(E1~E8)은 모바일 우선 반응형, 관리자/인사 화면(A/H)은 데스크탑 그리드 레이아웃 우선
